## Contributing
Contributing to Project Forecaster is very simple:
1. Fork it on GitHub
2. Install dependencies: `npm install` (Node.js 24 or later)
3. Add your contribution code (run `npm run dev` for a local server with hot reload)
4. Make sure everything passes: `npm run coverage` (100% coverage is enforced) and `npm run build`
5. Submit a pull-request

Thanks!
